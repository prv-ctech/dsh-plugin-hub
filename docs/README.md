## Reading order

1. Read reference.md before changing Harness integration.
2. Review architecture.md to understand the plugin boundary.
3. Use development.md for local checks and tagged releases.

## Verify Harness behavior

Check the official [Harness documentation](https://deepseek-harness.github.io/deepseek-harness/reference/) and [source repository](https://github.com/deepseek-ai/deepseek-harness) first. Confirm behavior against the installed Harness version, then use a minimal experiment only when documentation and source do not resolve the question. Record verified findings in reference.md.
